# Skilteplanen stylesheet

This is the UI style reference transcribed from the project stylesheet. Use the
shared values below when building components. The documented component variants
take precedence where a component has its own style.

## Colours and surfaces

| Element | Style | Value |
| --- | --- | --- |
| Brand blue | Primary links and outlined button text and border | `#1562AD` |
| Header and footer | Blue background, white text | `#1562AD` / `#FFFFFF` |
| Homepage hero | Dark blue to blue gradient | `#124B7A` → `#1C68AD` |
| Main text | Almost black | `#212121` |
| Secondary text | Grey | `#757575` |
| Page and panel background | White | `#FFFFFF` |
| Muted panel background | Light grey | `#F5F5F5` |
| Supporting section background | Very light blue-grey | `#F7F9FC` |
| Success | Green | `#4CAF50` |
| Error | Red | `#F44336` |

## Buttons

| Component | Style | Value |
| --- | --- | --- |
| Primary button | Blue background, white text | `#1562AD` / `#FFFFFF` |
| Secondary button | Dark grey background, white text | `#424242` / `#FFFFFF` |
| Outlined primary button | Blue text and border | `#1562AD` |
| Header signup button | White background, blue text | `#FFFFFF` / `#1562AD` |
| Signup button example | Gold background, navy text | `#FFD700` / `#15324F` |

Button text is semibold (`600`) and uses sentence case. The default corner
radius is `4px`; the homepage signup button uses `6px`.

## Typography

- Font: system sans-serif, using Segoe UI, Roboto, Helvetica, or Arial.
- Main body text: `16px`, regular weight, line height `1.6`.
- Secondary body text: `14px`, regular weight, line height `1.6`.

## Cards and panels

Cards and panels have rounded corners and soft shadows. Their corner radius
varies by component.

The source's sample labels and visual examples are illustrative. Component
overrides can differ from the shared theme, and the text sizes above refer to
the website rather than the scaled samples in the source document.
