# Frontend internationalization

The web app uses `i18next` with `react-i18next`. The instance is initialized
once in `src/config/i18n.ts`, which exports both the instance and its
initialization promise. Await initialization in `src/main.tsx` before rendering:

```ts
import { i18nReady } from './config/i18n.js';

await i18nReady;
```

Keep translations grouped by language. For
`apps/web/locales/en/translation.json`, use:

```json
{
  "home": {
    "title": "Welcome",
    "greeting": "Hello, {{name}}!"
  }
}
```

For `apps/web/locales/da/translation.json`, use:

```json
{
  "home": {
    "title": "Velkommen",
    "greeting": "Hej, {{name}}!"
  }
}
```

Register each file in the `resources` option in `src/config/i18n.ts` under its
language code and the `translation` namespace. Keep the fallback language
consistent with the languages the app supports.

## Translating React components

Use the `useTranslation` hook in React components. It subscribes the component
to language changes, so translated text updates when the active language
changes:

```tsx
import { useTranslation } from 'react-i18next';

export function HomePage() {
  const { t } = useTranslation();

  return (
    <main>
      <h1>{t('home.title')}</h1>
      <p>{t('home.greeting', { name: 'Ada' })}</p>
    </main>
  );
}
```

Translation keys use dot notation to address nested JSON properties.
Interpolation values are passed as the second argument; in the example,
`{{name}}` is replaced with `Ada`.

## Calling `i18n.t()` directly

You can import the configured instance and call `i18n.t()` when you need a
translation outside a React component, or for a one-off value:

```ts
import i18n from '../config/i18n.js';

const title = i18n.t('home.title');
const greeting = i18n.t('home.greeting', { name: 'Ada' });
```

Avoid calling `i18n.t()` during a component render when the text must update
after a language change. A direct call does not subscribe the component to
language changes; use `useTranslation()` for rendered UI.

Change the active language with the instance:

```ts
await i18n.changeLanguage('da');
```

Components using `useTranslation()` will update to the selected language.

## Extracting and checking translation keys

Run the extraction script from `apps/web` to add keys found in the source code
to the locale JSON files:

```bash
bun run locale:extract
```

Check that every extracted key has a non-empty translation in each locale,
without modifying the locale files:

```bash
bun run locale:check
```

The check extracts keys into a temporary directory, then compares them with
the locale JSON files. It reports keys that are absent or have an empty value
and exits with an error if any are found. Extraction output is temporary; the
check never writes to the locale JSON files. After adding translation calls,
run extraction and fill in the new translations.
